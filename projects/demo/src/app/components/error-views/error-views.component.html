This board was saved by a session that had all three widget types. None of them is registered here, so every cell asks UNKNOWN_WIDGET_RESOLVER what to render instead - and this page answers differently for each: the revenue breakdown is withheld from the session, the site map belongs to a feature module that has not loaded, and the forecast falls through to the library's default view, because the resolver returns null for it.

Loading a widget type registers it, unloading takes it away again. The cell heals in place either way, keeping the state it was loaded with - no reload, no second load of the dashboard data.
